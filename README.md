# When check-in falls apart at 1:45 AM · Airbnb late-night arrival

A single-page, scroll-driven product design case study. Plain HTML, CSS and a small script: no framework, no build step.

- `index.html`: content
- `styles.css`: all visuals and animation
- `main.js`: turns scroll position into CSS custom properties and `data-*` attributes
- `img/`: screens and boards exported from the Figma file

To preview locally, serve the folder with any static server, for example `npx http-server`.
